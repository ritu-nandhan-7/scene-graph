# Scene Graph Generation using YOLO-World and CLIP

## Overview

This project predicts relationships between detected objects in an image to generate a complete scene graph.

Pipeline:

Image
↓
YOLO-World
↓
Objects + Bounding Boxes
↓
Relationship Prediction Model
↓
Scene Graph
